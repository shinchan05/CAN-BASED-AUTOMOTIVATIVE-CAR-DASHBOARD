🚗 CAN-Based Automotive Dashboard

A real-time automotive dashboard developed using the Controller Area Network (CAN) Protocol to monitor, process, and display vehicle data. This project demonstrates automotive communication, embedded systems programming, and real-time data visualization by decoding CAN messages and presenting vehicle parameters on a dashboard interface.

 🚀 How It Works
📡 CAN messages are received from the CAN bus.
🔍 The microcontroller decodes incoming CAN frames.
⚙️ Vehicle parameters are extracted and processed.
📊 The dashboard updates in real time.
🚨 Any abnormal conditions trigger warning indicators.
